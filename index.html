MSpektra GitHub

See every mass in your spectrum.

LC-MS and HRMS analysis with protein deconvolution, for Windows.

Download for Windows Release notes
Latest version. Free. Nothing to install.

LCMS Analysis

Chromatograms, MS and PDA, peak integration and a view to compare runs. Shimadzu, Agilent, Waters, Thermo, mzML and ANDI files.

HRMS Analysis

Calibration, exact mass and a formula finder. Bruker (including timsTOF), Agilent, Waters, Thermo Orbitrap and mzML.

Deconvolution

Intact protein masses with UniDec, maximum entropy and IsoDec, with reports in PDF and Word.

Getting started

  1. Download MSpektra-<version>.zip from the latest release.
  2. Extract it to a short folder path, for example the Desktop.
  3. Start MSpektra.exe. New versions install with one click.
