MSpektra

LC-MS and HRMS analysis with deconvolution, for Windows.

Download the latest version Free, MIT License. Nothing to install.

What it does

LCMS Analysis

Chromatograms, mass spectra, PDA and UV data, peak integration and a view to compare runs.

  • Shimadzu .lcd
  • Agilent .D
  • Waters .raw
  • Thermo .raw
  • mzML
  • mzXML
  • ANDI .cdf

HRMS Analysis

High resolution mass spectra with calibration, exact mass and a formula finder.

  • Bruker .d
  • timsTOF
  • Agilent MassHunter
  • Waters .raw
  • Thermo Orbitrap
  • mzML

Deconvolution

Intact protein masses from charge state series, with reports in PDF and Word.

  • UniDec
  • Maximum entropy
  • IsoDec
  • Isotope resolved

Getting started

  1. Download MSpektra-<version>.zip from the latest release.
  2. Extract it to a short folder path, for example the Desktop.
  3. Start MSpektra.exe. New versions install themselves with one click.
