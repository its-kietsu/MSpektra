Bruker Baf2Sql library (baf2sql_c.dll, version 2.9.0)

Used by HRMS Analysis (MSpektra) to read Bruker .d folders with
analysis.baf (maXis, impact, compact, micrOTOF and other Bruker instruments).

The library is Bruker Daltonics software, freely distributed by Bruker for
reading BAF data (it is also shipped with ProteoWizard). This copy comes from
the pyBaf2Sql project (https://github.com/gtluu/pyBaf2Sql, Apache-2.0 for the
Python code), which redistributes Bruker's library.

It uses the Intel Math Kernel Library and other third-party software; their
licence terms are in THIRD-PARTY-LICENSE-README.txt and BAF2SQL_README.txt.

MSpektra only calls the library's public C functions (via ctypes, see
hrms_data.py); the library itself is unchanged.
